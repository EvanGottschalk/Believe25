# Additional Pages

Every page beyond the landing page, what it does, and where its frontend lives.

Routes fall into three groups: **section pages** (a landing-page Body section rendered standalone), **commerce and custom pages** (real pages, outside the section registry), and **legal pages**.

---

## Section pages

Generated by one dynamic route from the registry in `config/sections.ts`. Adding a Body section with a `slug` creates its page automatically — no new file.

**Route file:** `app/[section]/page.tsx`
**Renderer:** `components/SectionRenderer.tsx` (shared with the landing page, so a section renders identically in both places; only the `standalone` prop differs)

| Path | Section | Component | Purpose |
|---|---|---|---|
| `/phone-chain` | What Is a Phone Chain? | `components/body/PhoneChainSection.tsx` | Explains the flagship product — the sticky-scroll sequence covering wrist / hands-free / worn-as-jewelry. |
| `/collection` | The Collection | `components/body/CollectionSection.tsx` | Curated products plus the category strip. Shoppable; every tile carries both Add to Bag and Make it yours. |
| `/made-for-you` | Made For You | `components/body/CustomSection.tsx` | How the custom process works, five steps, plus the live 3-question teaser. Routes on to `/custom`. |
| `/about` | The Believe25 Story | `components/body/StorySection.tsx` | The maker's story and workshop imagery. |

Unknown or disabled slugs 404. Section slugs are validated against `RESERVED_SLUGS` at module load, so a future section can never shadow `/shop` or `/custom`.

## Commerce pages

| Path | File | Purpose |
|---|---|---|
| `/shop` | `app/shop/page.tsx` | Full catalog. Filterable by category via `?category=<handle>`. Renders `ProductGrid`; falls back to an empty state that still offers the custom path. |
| `/shop/[handle]` | `app/shop/[handle]/page.tsx` | Product detail. Gallery, variant picker, live price and stock, materials/dimensions/care, Add to Bag, a Make it yours card, related items, and `Product` JSON-LD. Statically generated for every product via `generateStaticParams`. |

The cart is not a page — it's a slide-over (`components/commerce/CartDrawer.tsx`) mounted once in `app/layout.tsx` and available everywhere. Checkout is hosted by Shopify; we redirect to `cart.checkoutUrl`.

## Custom design pages

| Path | File | Purpose |
|---|---|---|
| `/custom` | `app/custom/page.tsx` | The full six-question style questionnaire plus a contact step. Accepts seed answers as query params (e.g. `/custom?piece=phone-chain&palette=iridescent`) so answers given in the landing-page teaser aren't asked twice, and `?from=<product-handle>` to record which product the visitor came from. Progress is persisted to `sessionStorage`. Frontend: `components/custom/StyleQuiz.tsx`. |
| `/custom/thank-you` | `app/custom/thank-you/page.tsx` | Confirmation after a request is submitted. `noindex` — it's a flow endpoint, not a landing page. |

Requests take no payment. Submissions POST to `/api/custom-request`, which validates every answer against `config/forms.ts` server-side, rate-limits by IP, and forwards to `CUSTOM_FORM_ENDPOINT`.

## Legal pages

All three share one presentational component, `components/layout/LegalPage.tsx`, and take their content from `config/legal.ts`. While `LEGAL_IS_DRAFT` is true each page shows a draft notice.

| Path | File | Content source |
|---|---|---|
| `/privacy` | `app/privacy/page.tsx` | `PRIVACY` |
| `/terms` | `app/terms/page.tsx` | `TERMS` |
| `/shipping-returns` | `app/shipping-returns/page.tsx` | `SHIPPING_RETURNS` |

## Utility routes

| Path | File | Purpose |
|---|---|---|
| `/sitemap.xml` | `app/sitemap.ts` | Landing page, section pages, every product, and legal pages. |
| `/robots.txt` | `app/robots.ts` | Disallows `/api/` and `/custom/thank-you`. |
| 404 | `app/not-found.tsx` | Routes back to the collection. |

## API routes

Not pages, but listed for completeness. All live under `app/api/`.

| Route | Purpose |
|---|---|
| `/api/cart` | All cart mutations. Keeps the Storefront token server-side — the browser only ever holds a cart id. |
| `/api/custom-request` | Receives style questionnaires; validates, rate-limits, forwards. |
| `/api/newsletter` | Newsletter signup. Supports Klaviyo, Mailchimp and ConvertKit. |
| `/api/revalidate` | Shopify `products/update` webhook. Purges cached product data so price and stock changes go live without a deploy. |
